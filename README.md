# Nocturne (تطبيق الموبايل وواجهة الساعة الذكية)

تطبيق أندرويد متكامل يجمع بين:
1. **تطبيق مرافق للهاتف (Nocturne Phone Companion):** مبني بتقنيات Android الحديثة (Kotlin + Jetpack Compose + Material 3) لمعاينة واجهة الساعة في وضعي النشط (Active) والاستعداد (AOD)، والتحكم في إعدادات الثيمات وتطبيقها على الساعة.
2. **واجهة ساعة مستقلة (Nocturne Wear OS Watch Face):** مصممة بمعمارية **Watch Face Format (WFF)** الرسمية بنسخة قابلة للتثبيت والتخصيص المباشر على ساعات Wear OS (خاصة **Samsung Galaxy Watch 5** بنظام Wear OS 6).

---

## 🎨 الثيمات المدعومة (Watch Face Themes)

### 1. Sage Nocturne (التصميم العثماني الأخضر الأصلي)
- **الزخرفة العثمانية:** نقش أرابيسك عثماني فاخر على الجانب الأيسر مع خيارات كثافة متعددة (متوازن، بسيط، مزخرف، بدون).
- **ألوان الميناء:** أخضر سيج مطفي أصلي، أزرق نيلي، ذهبي عتيق، زمردي، وفضي.
- **القمر الصغير:** في موضعه الأصلي أعلى الميناء ($x=392, y=122, 216\times216$)، مع معالجة فلكية ثلاثية الأبعاد لـ 29 منزلة كاملة، وتضمين إضاءة الأرض المرتدة (Earthshine) وحافة المحاق المضيئة بدقة.
- **العقارب المفرغة:** عقارب أنالوج هندسية مفرغة تحافظ على التصميم الكلاسيكي الأنيق.
- **التعقيدات:** خانة البطارية (اليسرى)، خانة التاريخ والتقويم (اليمنى)، وخانة عداد الخطوات (السفلية)، مع حلقة دقيقة تحيط بكل خانة.
- **الأذكار:** نصوص ذكر تتغير دورياً بدقة فائقة.

### 2. Lunar Phase (القمر السينمائي الكبير)
- **وضع Active:** قرص قمر ثلاثي الأبعاد كبير يملأ 92% من واجهة الساعة ($920\times920$)، مع تغير فلكي واقعي لزاوية سقوط أشعة الشمس على تضاريس القمر الحقيقية، وعقارب تباين مزدوج (إطار فحمي وجسم مضيء) تضمن قراءة واضحة فوق الجزء المظلم والمنير.
- **وضع AOD:** خلفية سوداء تامة لحفظ البطارية، يختفي معها القمر وعقرب الثواني، وتظهر أرقام ساعات كلاسيكية وعلامات دقايق فضية متطابقة في محاور الارتكاز.

## 🚀 التحميل والتثبيت (Download & Installation)

يمكنك تحميل أحدث نسخ الـ APK مباشرة من صفحة الإصدارات:
👉 **[تحميل Nocturne من GitHub Releases](https://github.com/MZAYED2/Nocturne/releases)**

### 📱 1. تثبيت تطبيق الموبايل (Galaxy S25 Ultra):
- قم بتحميل `Nocturne-Phone-*.apk` وافتحه على هاتفك لتثبيته مباشرة.

### ⌚ 2. تثبيت واجهة الساعة (Galaxy Watch 5):
1. فعّل **خيارات المطور (Developer Options)** في الساعة:
   - الإعدادات -> حول الساعة -> معلومات البرنامج -> اضغط على "رقم الإصدار" 7 مرات.
2. فعّل **تصحيح أخطاء اللاسلكي (Wireless Debugging)**.
3. من موجه الأوامر (Terminal) على الكمبيوتر:
   ```bash
   adb connect <عنوان_الساعة_IP>:5555
   adb install -r Nocturne-Watch-*.apk
   ```
4. على الساعة: اضغط مطولاً على شاشة الساعة لاختيار واجهة **Nocturne** وتخصيصها.

## 🛠 البناء محلياً من السورس (Building from Source)

```bash
# بناء تطبيق الموبايل:
./gradlew :app:assembleDebug

# بناء واجهة الساعة:
./gradlew :watchface:assembleDebug

# بناء كل المخرجات:
./gradlew assembleDebug
```
